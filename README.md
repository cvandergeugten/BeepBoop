## IMPORTANT REPOSITORY RULES

- Please DO NOT commit anything to the main branch. Always make changes to the project in a separate branch and then open a Pull Request (PR).
- After a Pull Request has been opened DO NOT merge into main until it has been approved by the repository owner (Chance V). This rule will become more relaxed over time as team members learn to use git and are able to contribute responsibly to the project.

**Failure to follow these instructions will result in a verbal warning.**

**Continued offenses related to these rules will result in removal from the group.**

## Game Design Principles

Key design motifs for this project:
- **Toy Box:** Creating a playful environment where players can experiment and enjoy themselves.
- **Embrace Distraction:** Incorporating fun, whimsical elements that keep players engaged and entertained.
- **Comical:** Ensuring that humor is woven into the gameplay through lighthearted puzzles and interactions.
